#   <Member>      the member function that reads it (default: <Type>::Load, else Size_Of); its unit's layouts are taken;
#   size=<n>      the original's object size, which the i686 layout must equal (the immediate its Size_Of,
#                 vtable slot 12, returns; a locomotor's Size, slot 9; or a literal read size);
#   load=<addr>   the original address of its Load: when a rename leaves the name unknown, the check names
#                 the class that now carries that address (polymorphic types get the nearest RTTI names).
# The other records the loads read (members, list elements, structs) are taken from the units
# that read streams; see the tool.
#
